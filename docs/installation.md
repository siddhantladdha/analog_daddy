# Installation

## Stable release

To install Analog Daddy, run this command in your terminal:

```sh
uv add analog-daddy
```

Or if you prefer to use `pip`:

```sh
pip install analog-daddy
```

## From source

The source files for Analog Daddy can be downloaded from the [Github repo](https://github.com/siddhantladdha/analog_daddy).

You can either clone the public repository:

```sh
git clone https://github.com/siddhantladdha/analog_daddy
```

Or download the [tarball](https://github.com/siddhantladdha/analog_daddy/tarball/main):

```sh
curl -OJL https://github.com/siddhantladdha/analog_daddy/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd analog_daddy
uv sync
```
